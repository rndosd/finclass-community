## 먼저 알아둘 것

- 설치마다 운영자 소유의 Firebase 프로젝트와 Cloudflare R2 버킷을 사용합니다.
- 기존 서비스의 계정·학생 명단·학급 기록·파일·API 키는 포함하거나 자동 연결하지 않습니다.
- 웹페이지 파일만 호스팅해서는 거래 기능이 동작하지 않습니다. 서버 함수, 규칙과 인덱스도 필요합니다.
- 원본 서비스는 **2026학년도 2학기까지 운영하고 종료합니다.**
  공개 코드의 유지보수와 개별 설치 지원은 보장하지 않습니다.
- 서버와 외부 API 비용, 개인정보 처리 안내, 백업·복구, 계정 관리와 문의는 각 설치본 운영자가 맡습니다.

## 설치 순서

1. [구조와 연결 대상](docs/architecture.md)을 읽고 본인 명의의 프로젝트를 준비합니다.
2. [설치·배포 안내](docs/setup.md)에 따라 Firebase, R2와 필요한 외부 API를 연결합니다.
3. [운영 안내](docs/operations.md)에 따라 관리자 계정, 교사 학급과 가짜 학생을 만듭니다.
4. [검증과 공개 전 확인](docs/release-checklist.md)을 통과한 뒤 실제 이용을 시작합니다.

## 개발 명령

Node.js 22와 npm을 사용합니다. 서버 함수의 선언된 런타임은 Node.js 22입니다.

```sh
npm ci
npm --prefix functions ci
```

`.env.example`을 `.env.local`로 복사하고 **자기 프로젝트의 값**을 입력한 뒤 실행합니다.
예시 값을 그대로 사용하면 시작 명령이 실패합니다.

```sh
npm start
npm run test:core
npm run test:backend
npm run build
```

`npm start`도 기본적으로 설정한 실제 Firebase에 연결합니다. 학생 데이터를 쓰지 않는
별도 개발 프로젝트 또는 설치 안내의 로컬 에뮬레이터 모드를 사용하세요.

## 첫 공개 버전에서 제외하는 내용

자가 서버/Postgres 복제 실험, MCP·ChatGPT 계정 연결 초안, 특정 계정에만 연결된 Jev 실험,
로컬 경제학습 시안, 아바타 실험실, UI 미리보기, 분석 노트북과 결과, 운영 로그·백업·스냅샷,
기존 환경설정·인증정보·Git 이력은 포함하지 않습니다.
자동화 회귀 테스트의 합성 입력은 실제 운영 데이터와 구분하여 유지합니다.

기존 API 키 방식 AI는 별도 외부 연동입니다. ChatGPT 구독으로 연결되는 기능이 완성됐다고
안내하지 않습니다. [외부 서비스 설정](docs/setup.md#외부-api와-서버-secret)을 확인하세요.
