# 첫 공개판 검증

- 원본 Git 이력·설정·운영 로그·데이터·실험 영역을 제외한 별도 소스입니다.
- 기반 초안 준비 도구 10개, 서버 합성 회귀 247개, 프런트엔드 핵심 검사 8개가 통과했습니다.
- 전체 학급 운영자 기능을 제거하며 인증/플랜 서버 모듈을 수정했습니다. 유지한 함수 15개는 원래 표현식과 동일하며, 변경한 서버의 검증 결과를 아래에 기록합니다.
- 새 컴퓨터에서 npm ci, Node 22의 별도 설치, 새 Firebase/R2 프로젝트에서의 로그인·거래·권한·업로드,
  전체 브라우저 화면은 아직 확인하지 않았습니다. 실제 운영 전에 별도 개발 환경에서 확인하세요.
- 프로젝트 AI 제작·자체 제작 그림은 유지하고, 외부 로고·미확인 공용 이미지와 음원은 대체했습니다.
- 실험 기능을 제거하며 생긴 미사용 선언·hook dependency 경고와 도구의 경고가 남아 있습니다.
  빌드 성공을 경고 0건 또는 전체 운영 검증으로 해석하지 않습니다.

## 최종 공개 파일 확인

- 이 공개판의 프런트엔드 핵심 검사: 3개 suite, 8개 test 통과.
- 이 공개판의 최적화 production build: 성공, 경고 남음.
- 변경된 서버의 합성 회귀 검사 247개 통과. 유지한 인증/플랜 함수 15개의 표현식이 원래 코드와 동일함을 확인했습니다.
- 프로젝트 제작 그림 2,873개를 유지하고 외부 로고·미확인 공용 이미지·음원 24개를 대체했습니다.
- 로컬 Node v24.13.1과 기존 작업 공간 의존성을 재사용했습니다.
  선언된 Node 22의 새 설치 또는 새 계정에서의 전체 동작을 확인했다는 의미는 아닙니다.
- 저장소는 기존 운영 저장소의 이력 없이 새 첫 커밋으로 생성합니다.

## 전체 학급 운영자 기능 제거

전체 학급·교사 조회 화면 5개와 활동 순위 모달, 전체 통계·전송량 계측 모듈을 제외했습니다. 교사 승인·거절, 교사 플랜 일괄 조회, 전체 학급 초기화 callable을 제거했습니다. 일반 학생·수업·거래의 권한 규칙은 유지합니다. 변경 후 준비 도구 검사 11개, 서버 합성 회귀 검사 247개, 프런트엔드 핵심 검사 8개와 production build가 통과했습니다. 빌드 경고는 남아 있으며, 전체 브라우저·새 클라우드 환경의 실행은 이번 변경에서 확인하지 않았습니다.
