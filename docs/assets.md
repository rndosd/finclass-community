# 첫 공개판의 이미지와 음원

프로젝트의 AI 제작·자체 제작 칭호·삽화·화면 장식은 그대로 포함합니다.
외부 스포츠 로고·등급 이미지와 제작 출처가 불분명한 공용 로고는 대신,
이 공개판을 위해 새로 그린 중립적인 회색 아이콘을 넣었습니다.
대체 이미지에는 원래 픽셀과 이미지 메타데이터를 사용하지 않았습니다.
원래 음원은 새로 만든 무음 WAV로 대체했습니다. 폰트는 포함된 OFL 고지를 따릅니다.

기존 import, 자산 선택 키, 파일명과 이미지 형식을 유지하므로 연결 경로는 그대로입니다.
프로젝트 그림의 시각적 구분은 유지하며 외부 로고·공용 등급 이미지의 원래 디자인은 제공되지 않습니다.
각 운영자가 재배포할 권리를 확보한 자신의 이미지로 같은 경로의 파일을 교체할 수 있습니다.
스포츠 팀 이름과 경기 데이터는 이미지와 별개이며 외부 제공자의 조건을 확인해야 합니다.
