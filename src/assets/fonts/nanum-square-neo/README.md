# NanumSquare Neo

Unmodified NAVER NanumSquare Neo Regular, Bold and ExtraBold WOFF files.
Licensed under SIL Open Font License 1.1; see LICENSE.txt.

Official source: https://hangeul.pstatic.net/hangeul_static/css/nanum-square-neo.css
License source: https://help.naver.com/service/30016/contents/18088?lang=ko&osType=PC

The application uses static 400, 700 and 800 faces with font-display: swap.
No font CDN request is made at runtime. Contract serif/stamp fonts remain separate.
